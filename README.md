
# Pharmacy Inventory Management System

## Project Overview
A beginner Python project that simulates basic pharmacy inventory operations using Object-Oriented Programming (OOP).

## Features
- Store medicine names, prices, and quantities.
- Calculate the total value of medicines in stock.
- Restock medicines by increasing their quantities.
- Sell medicines while checking stock availability.
- Prevent sales when there is insufficient stock.

## OOP Concepts Practiced
- **Classes and Objects:** Represent medicines as objects.
- **Constructors (`__init__`):** Initialize medicine details.
- **Instance Attributes:** Store each medicine's name, price, and quantity.
- **Instance Methods:** Calculate stock value, restock medicines, and process sales.
- **Conditional Statements:** Validate stock availability before selling medicines.

## Technologies Used
- Python 3

## How to Run
1. Install Python 3.
2. Clone or download this repository.
3. Open a terminal in the project directory.
4. Run the following command:

   ```bash
   python main.py
   ```

## Example
For a medicine priced at KSh 20 with 100 units in stock:

- Initial stock value: KSh 2,000
- After restocking 50 units: 150 units
- After selling 30 units: 120 units remaining
